# Reference build — מהירות האור שליחויות

The finish level the user accepted ("high end", Vlad's benchmark): signature preset, night image hero + Veo loop,
moving vehicles (road, route, hero ride, scroll progress), bento tiles, light lead band, dark footer.
Build it to see the bar: `bin/zs new ref "מהירות האור" --from examples/mehirut-haor && bin/zs build ref`.
`BRIEF-CHECK.md` is the model for checking a site against its איפיון; `NOTES.md` for recording facts with sources.
The round-by-round story is in `.claude/skills/zap-site/references/playbook.md`. Real client data: use only as a pattern.
