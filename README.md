# בונה האתרים של זאפ

מבריף של לקוח לקובץ zip מוכן להעלאה לשרת: WordPress + Elementor, עברית, מוכן ל-SEO, עם בדיקות במדידה.
רץ ב-Claude Code בענן (claude.ai/code), כמה אתרים במקביל, בלי שום התקנה אצלכם במחשב.

## שימוש — כל אתר

1. נכנסים ל-**claude.ai/code**, בוחרים את הריפו `zap-site-builder` ואת הסביבה **zap-sites**.
2. כותבים `/zap-site` ומדביקים את הבריף (טקסט, קבצים, לוגו, תמונות, קישור לאתר הישן). זה הכול.
3. Claude חוקר את העסק, שואל **הודעה אחת** עם מה שחסר, ובונה.
4. **עצירה אחת:** מקבלים קישור לתצוגה של 3 כיווני עיצוב (מחשב + נייד) ואת עץ האתר עם מילות המפתח.
   עונים באות (A/B/C) ומאשרים את העמודים. רוצים בלי עצירות? כותבים "בלי עצירות".
5. בסוף מקבלים קישור להורדת ה-zip + צ'קליסט עלייה. את ה-zip מעבירים לאחראי השרת.

**כמה אתרים במקביל:** פותחים סשן חדש לכל לקוח. כל אתר עובד בענף משלו (`site/<slug>`) ולא מתנגש באחרים.

**תיקונים מהלקוח:** באותו סשן (או חדש: "תמשיך את האתר <slug>"), שולחים את כל ההערות בהודעה אחת.
Claude מעדכן, בונה, בודק ואורז מחדש.

## מה יש בתוך ה-zip

- `public_html/` — אתר וורדפרס מלא (ליבה, תבנית, תוספים, תמונות)
- `database.sql` — כל הכתובות כבר מכוונות לדומיין של הלקוח
- `deploy.sh` — התקנה בפקודה אחת על השרת (CloudPanel / כל שרת עם wp-cli)
- `DEPLOY.md`, `LAUNCH-CHECKLIST.md`, `QA-REPORT.md`

## הגדרה חד-פעמית (מנהל)

1. claude.ai/code → סביבות → **סביבה חדשה** בשם `zap-sites`:
   - **Network access: Full** (צריך wordpress.org)
   - **Setup script:** `bash bin/setup-cloud.sh`
   - משתני סביבה (לא חובה): `OPENAI_API_KEY` לתמונות AI · `ZS_SHAREPOINT_FLOW_URL` לשמירה ב-SharePoint
2. לוודא שאפליקציית Claude ב-GitHub מותקנת עם גישה לריפו.
3. בדיקה: בסשן חדש להריץ `bin/zs doctor` — כל השורות OK.

## איך זה בנוי (בקצרה)

Claude כותב את התוכן וההחלטות לקובץ אחד, `sites/<slug>/site.json`. מנוע (`bin/zs`) הופך אותו לאתר אמיתי:
ספריית סקשנים מעוצבת ובדוקה → עמודי Elementor שאפשר לערוך, תבנית אחידה עם הדר/פוטר/טופס לידים,
Yoast, סכמה, נגישות ותקני זאפ. לפני הבנייה יש **ולידציה** (מילת מפתח לכל עמוד, אין דירוגים מומצאים,
טלפון שמחייג למספר המוצג...), ואחריה **QA במדידה** על כל עמוד במחשב ובנייד. אריזה נחסמת כל עוד יש שגיאות.
