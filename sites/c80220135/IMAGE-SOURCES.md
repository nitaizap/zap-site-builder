## Notes on the marque trademarks

**Corrected 2026-11-04.** The spec sheet attaches its own logo files, and the `brief.md` text export drops
embedded images silently, so the first pass never saw them. Opening the `.docx` as a zip shows three PNGs in
`word/media/`: the current **Mazda** lockup, **Dongfeng** and **Voyah**. The spec's line next to them reads
"להשתמש רק בלוגו המעודכן של מאזדה (המצורף), ולא בלוגו הישן" — use only the attached, updated Mazda logo and
not the old one. The band had been built with the client's `F:` file, which is the **old** chrome-and-gradient
Mazda wordmark, i.e. exactly the logo the spec forbids. All three are now the files the client attached.

Ford is unchanged and still comes from the client's existing site, which is what the spec asks for
("לוגו פורד – מהאתר הקיים"). No business logo is embedded anywhere in the `.docx`: the spec's "אין לוגו לעסק"
is confirmed by the file itself, so the header stays as the styled business name (OPEN-ITEMS 3).

`assets/logo-dongfeng.png` and `assets/logo-voyah.png` (the copies taken from dongfeng.co.il in the first
pass) are kept in the repo as the untouched originals of the superseded rows above, but nothing on the site
points at them any more.

Marque logos are **trademarks, not stock photography**: the question is permitted use rather than a
photographer's copyright. An authorised service centre showing the marques it is licensed for is ordinary
practice, the client's existing site already does it for Mazda and Ford, and the client supplied the other
three marks itself in the spec sheet, which is as close to the importer's sign-off as the paperwork gets.
